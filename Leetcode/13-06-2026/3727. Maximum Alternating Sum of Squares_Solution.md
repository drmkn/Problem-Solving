# 3727. Maximum Alternating Sum of Squares

**LeetCode:** [3727. Maximum Alternating Sum of Squares](https://leetcode.com/problems/maximum-alternating-sum-of-squares/description/?envType=daily-question&envId=2026-10-13)
    

## Solution
    
```python
    class Solution:
    def maxAlternatingSum(self, nums: List[int]) -> int:
        
        n = len(nums)

        abs_l = []

        for e in nums:
            abs_l.append(abs(e))

        abs_l.sort(reverse=True)

        k = int(math.ceil(n/2))

        ans = 0
        for e in abs_l:
            if k > 0:
                ans += e*e
                k-=1
                continue
            ans -= e*e

        return ans
