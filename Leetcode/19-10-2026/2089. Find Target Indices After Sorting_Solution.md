# 2089. Find Target Indices After Sorting

**LeetCode:** [2089. Find Target Indices After Sorting](https://leetcode.com/problems/find-target-indices-after-sorting-array/description/?envType=daily-question&envId=2026-10-19)
    

## Solution
    
```python
    class Solution:
    def targetIndices(self, nums: list[int], target: int) -> list[int]:

        # #nlogn
        # nums.sort()
        # L = []
        # for i,e in enumerate(nums):
        #     if e == target:
        #         L.append(i)

        #O(n)
        c_s,c = 0,0
        # L = []
        for i,e in enumerate(nums):
            if e < target:
                c_s += 1
            elif e == target:
                c += 1
        

        
        return [ i for i in range(c_s,c_s+c)]
