# 453. Minimum Moves to Equal Array Elements

**LeetCode:** [453. Minimum Moves to Equal Array Elements](https://leetcode.com/problems/minimum-moves-to-equal-array-elements/description/?envType=daily-question&envId=2026-11-01)
    

## Solution
    
```python
    class Solution:
    def minMoves(self, nums: list[int]) -> int:
        
        n = len(nums)

        m = min(nums)

        ans = 0

        for e in nums:
            ans += (e-m)
        
        return ans
