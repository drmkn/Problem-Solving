# 4097. Minimum Value of Merged Integers

**LeetCode:** [4097. Minimum Value of Merged Integers](https://leetcode.com/problems/minimum-value-of-merged-integers/description/)
    

## Solution
    
```python
    class Solution:
    def minMergedInteger(self, nums: list[int]) -> int:
        l = []
        n = len(nums)

        for i in range(0,n,2):
            l.append(int(str(nums[i])+str(nums[i+1])))

        return min(l)
