# 4092. Binary Digit Score

**LeetCode:** [4092. Binary Digit Score](https://leetcode.com/problems/binary-digit-score/description/)
    

## Solution
    
```python
    class Solution:
    def calculateScore(self, a: int, b: int) -> int:
        # M = (1 << 32) - 1
        # A = (a&M)
        def compute(a):
            c = 0
            while (a):
                c += (1&a)
                a = a >> 1
            return c
            
        A,B = compute(a),compute(b)

        if A >= B:
            return A*B
        else:
            return B//A
