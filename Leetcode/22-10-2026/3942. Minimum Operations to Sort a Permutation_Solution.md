# 3942. Minimum Operations to Sort a Permutation

**LeetCode:** [3942. Minimum Operations to Sort a Permutation](https://leetcode.com/problems/minimum-operations-to-sort-a-permutation/description/?envType=daily-question&envId=2026-10-22)
    

## Solution
    
```python
    class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)

        ideal = [i for i in range(n)]

        if ideal == nums:
            return 0



        #check feasibility
        zero_index,max_index = nums.index(0),nums.index(n-1)
        # print(zero_index,max_index)

        if nums[(zero_index-1)%n] == 1:
            cyc_arr = nums[:zero_index+1][::-1] + nums[zero_index+1:][::-1]
        elif nums[(zero_index+1)%n] == 1:
            cyc_arr = nums[zero_index:] + nums[:zero_index]
        else:
            return -1
        # print(cyc_arr)

        if cyc_arr != ideal:
            return -1

        if max_index <= n//2:
            return max_index+1
        else:
            return (n-max_index)+1
