# 462. Minimum Moves to Equal Array Elements II

**LeetCode:** [462. Minimum Moves to Equal Array Elements II](https://leetcode.com/problems/minimum-moves-to-equal-array-elements-ii/description/?envType=daily-question&envId=2026-11-02)
    

## Solution
    
```python
    class Solution:
    def minMoves2(self, nums: list[int]) -> int:
        
        nums.sort()
        n = len(nums)
        m = nums[n//2]
        k = n//2
        ans = 0

        for i,e in enumerate(nums):
            if i <= k: 
                ans += (m-e)
            else:
                ans += (e-m)

        return ans
