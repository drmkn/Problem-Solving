# 2409. Count Days Spent Together

**LeetCode:** [2409. Count Days Spent Together](https://leetcode.com/problems/count-days-spent-together/description/?envType=daily-question&envId=2026-10-24)
    

## Solution
    
```python
    class Solution:
    def countDaysTogether(self, arriveAlice: str, leaveAlice: str, arriveBob: str, leaveBob: str) -> int:
        month_days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

        days = []
        for i,e in enumerate(month_days):
            if i == 0:
                days.append(month_days[i])
                continue
            days.append(month_days[i]+days[i-1])

        def get_day_number(day,month):
            if month == 1:
                return day
            return day+days[month-2]

        Alice_start_day,Alice_start_month = int(arriveAlice.split('-')[1]),int(arriveAlice.split('-')[0])
        Alice_end_day,Alice_end_month = int(leaveAlice.split('-')[1]),int(leaveAlice.split('-')[0])
        Bob_start_day,Bob_start_month = int(arriveBob.split('-')[1]),int(arriveBob.split('-')[0])
        Bob_end_day,Bob_end_month = int(leaveBob.split('-')[1]),int(leaveBob.split('-')[0])

        A_1,A_2 = get_day_number(Alice_start_day,Alice_start_month),get_day_number(Alice_end_day,Alice_end_month)
        B_1,B_2 = get_day_number(Bob_start_day,Bob_start_month),get_day_number(Bob_end_day,Bob_end_month)
        # print(A_1,A_2)
        # print(B_1,B_2)
        if A_1 <= B_1 and A_2 >= B_1:
            return min(A_2,B_2) - B_1 + 1
        if B_1 < A_1 and B_2 >= A_1:
            return min(B_2,A_2) - A_1 + 1
        
        return 0
