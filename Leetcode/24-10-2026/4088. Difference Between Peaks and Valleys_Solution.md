# 4088. Difference Between Peaks and Valleys

**LeetCode:** [4088. Difference Between Peaks and Valleys](https://leetcode.com/problems/difference-between-peaks-and-valleys/description/)
    

## Solution
    
```python
    class Solution:
    def peakValleyDifference(self, nums: list[int]) -> int:
        n = len(nums)

        peak_sum,valley_sum = 0,0

        for i,e in enumerate(nums):
            if i == 0 or i == n-1:
                continue
            if nums[i] > nums[i-1] and nums[i] > nums[i+1]:
                peak_sum += e

            if nums[i] < nums[i-1] and nums[i] < nums[i+1]:
                valley_sum += e

        return peak_sum - valley_sum
