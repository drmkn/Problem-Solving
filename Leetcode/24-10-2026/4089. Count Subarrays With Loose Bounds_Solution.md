# 4089. Count Subarrays With Loose Bounds

**LeetCode:** [4089. Count Subarrays With Loose Bounds](https://leetcode.com/problems/count-subarrays-with-loose-bounds/description/)
    

## Solution
    
```python
    class Solution:
    def countSubarrays(self, nums: list[int], minK: int, maxK: int) -> int:
        n = len(nums)
        
        
        ans = 0
        last_valid = -1
        for i in range(n):
            if nums[i] >= minK and nums[i] <= maxK:
                if last_valid != -1:
                    ans += (i-last_valid+1)
                else:
                    ans += 1
                    last_valid = i
            else:
                last_valid = -1
                
        # for i in range(n):
        #     for j in range(i,n):
        #         if nums[j] >= minK and nums[j] <= maxK:
        #             ans += 1
        #         else:
        #             break

        return ans
