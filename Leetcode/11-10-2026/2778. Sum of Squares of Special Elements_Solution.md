# 2778. Sum of Squares of Special Elements

**LeetCode:** [2778. Sum of Squares of Special Elements](https://leetcode.com/problems/sum-of-squares-of-special-elements/description/?envType=daily-question&envId=2026-10-11)
    

## Solution
    
```python
    class Solution:
    def sumOfSquares(self, nums: List[int]) -> int:

        ##single pass approach
        n = len(nums)
        ans = 0
        for i,e in enumerate(nums):
            if not n%(i+1):
                ans += e**2
            
        return ans
