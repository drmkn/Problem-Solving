# 1588. Sum of All Odd Length Subarrays

**LeetCode:** [1588. Sum of All Odd Length Subarrays](https://leetcode.com/problems/sum-of-all-odd-length-subarrays/description/)
    

## Solution
    
```python
    class Solution:
    def sumOddLengthSubarrays(self, arr: list[int]) -> int:
        n = len(arr)
        def divide_ceil(k):
            if k%2:
                return k//2+1
            return k//2
        freq = []

        for i,e in enumerate(arr):
            if i == 0:
                freq.append(divide_ceil(n-i))
                continue
            # if i < divide_ceil(n):
            e_e = ((n-i)//2)*((i+1)//2)
            o_o = (divide_ceil(n-i))*(divide_ceil(i+1))
            freq.append(e_e+o_o)
        # print(freq) 
        ans = 0

        for e1,e2 in zip(arr,freq):
            ans += e1*e2
        
        return ans
