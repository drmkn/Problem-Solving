# 3644. Maximum K to Sort a Permutation

**LeetCode:** [3644. Maximum K to Sort a Permutation](https://leetcode.com/problems/maximum-k-to-sort-a-permutation/description/?envType=daily-question&envId=2026-10-23)
    

## Solution
    
```python
    class Solution:
    def sortPermutation(self, nums: List[int]) -> int:
        n = len(nums)

        k = math.floor(math.log(n,2))
        M = (1 << (k+1)) - 1
        ans = M
        flag = 0
        # print(M)
        for i,e in enumerate(nums):
            if i != e:
                flag = 1
                ans &= e
        if flag:
            return ans
        else:
            return 0
