# 3963. Create Grid With Exactly One Path

**LeetCode:** [3963. Create Grid With Exactly One Path](https://leetcode.com/problems/create-grid-with-exactly-one-path/description/?envType=daily-question&envId=2026-10-27)
    

## Solution
    
```python
    class Solution:
    def createGrid(self, m: int, n: int) -> list[str]:
        
        grid = [(".")*n]

        for _ in range(m-1):
            grid.append(("#")*(n-1)+".")

        return grid
