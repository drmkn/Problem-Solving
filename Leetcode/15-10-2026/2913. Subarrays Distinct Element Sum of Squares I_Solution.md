# 2913. Subarrays Distinct Element Sum of Squares I

**LeetCode:** [2913. Subarrays Distinct Element Sum of Squares I](https://leetcode.com/problems/subarrays-distinct-element-sum-of-squares-i/description/?envType=daily-question&envId=2026-10-15)
    

## Solution
    
```python
    class Solution:
    def sumCounts(self, nums: List[int]) -> int:
        n = len(nums)
        temp = []
        for i in range(n):
            s = set()
            for j in range(i,n):
                if nums[j] not in s:
                    s.add(nums[j])
                temp.append(len(s))
        
        return sum([e*e for e in temp])
