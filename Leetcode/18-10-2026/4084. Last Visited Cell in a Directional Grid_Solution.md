# 4084. Last Visited Cell in a Directional Grid

**LeetCode:** [4084. Last Visited Cell in a Directional Grid](https://leetcode.com/problems/last-visited-cell-in-a-directional-grid/description/)
    

## Solution
    
```python
    class Solution:
    def lastVisitedCell(self, grid: list[list[str]]) -> list[int]:
        ## weekly contest 524
        n = len(grid)
        m=len(grid[0])

        visited = [[0]*m for i in range(n)]

        visited[0][0] = 1
        loc = [0,0]
        while True:
            cell = grid[loc[0]][loc[1]]
            last = loc.copy()
            
            if cell == 'R':
                loc[1] += 1
                # print(loc)
            elif cell == 'L':
                loc[1] -= 1
                # print(loc)
            elif cell == 'U':
                loc[0] -= 1
                # print(loc)
            else:
                loc[0] += 1
                # print(loc)

            if loc[0] > n-1 or loc[0] < 0:
                return list(last)
            if loc[1] > m-1 or loc[1] < 0:
                return list(last)
            if visited[loc[0]][loc[1]] == 1:
                return list(last)
            # print(grid)
            visited[loc[0]][loc[1]] = 1

        return list(last)
