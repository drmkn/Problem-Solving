# 3736. Minimum Moves to Equal Array Elements III

**LeetCode:** [3736. Minimum Moves to Equal Array Elements III](https://leetcode.com/problems/minimum-moves-to-equal-array-elements-iii/description/?envType=daily-question&envId=2026-11-03)
    

## Solution
    
```python
    class Solution:
    def minMoves(self, nums: List[int]) -> int:
        M = max(nums)

        ans = 0

        for e in nums:
            ans += M-e

        return ans
